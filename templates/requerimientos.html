Cómo fluye la información

Dos fuentesDatos técnicos (fuentes oficiales, gremios, prensa) y señales de campo desde el celular.
IA que escuchaEntiende el relato, protege la identidad, describe fotos y agrupa temas nuevos. Solo sugiere.
Validación humanaUna persona del equipo confirma o descarta cada señal.
Motor PESTELCalcula las dos lecturas, detecta brechas, prioriza, simula escenarios y sugiere acciones.
DevoluciónCompromisos con actores, informe, Excel y ficha para devolver la información y página pública de seguimiento.

Piloto actual

Python 3 con Flask, SQLite, Bootstrap 5, Chart.js, Leaflet e IA de Claude (Anthropic) con respaldo por reglas si no hay conexión.

Fase 2

FastAPI, PostgreSQL + PostGIS, React como app instalable, reportes por WhatsApp y notas de voz, y carga automática de clima y precios.

Fase 3

Varias organizaciones en una sola plataforma, alertas a los actores responsables y datos abiertos para aliados.
